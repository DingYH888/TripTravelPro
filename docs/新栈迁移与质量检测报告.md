### 1.3 核查中发现并修复的迁移缺口

1. 前台路由把首页、列表、详情也设为登录可见，与原匿名浏览行为不一致；已改为仅收藏需登录。
2. 注册邮件激活链接仍指向旧地址 `/frontdesk/member/active?activeCode=`；已改为新前台 `/activate?code=`，登录引导改为 `/login`。
3. 后台线路描述由 WangEditor 降级为纯文本框，且限制 500 字；已新增 `RichTextEditor.vue`，支持加粗、斜体、下划线、标题、列表、链接、图片上传与清除格式。
4. 详情富文本使用 `v-html` 渲染，存在存储型 XSS 风险；已新增 `sanitizeHtml` 白名单清洗，并应用于线路详情与激活结果。
5. 旧 `MyUserDetailService` 删除后，Spring Boot 自动生成了无用的默认安全用户；已在启动类排除 `UserDetailsServiceAutoConfiguration`。
6. `logback.xml` 使用未定义的 `${catalina.base}`，运行时会生成 `catalina.base_IS_UNDEFINED/logs`；已改为 `logs` 并加入 `.gitignore`。
7. 清理旧静态资源时误删了 `resources/static/upload/img/product/**` 下 361 张商品图片，导致线路卡片与详情图 404；已从版本库恢复，并让 `WebMvcConfig` 在运行期上传目录找不到文件时回退到 `classpath:/static/upload/`。
8. 两个 Vite 应用的 `/upload` 开发代理仍指向 8080，而后端运行在 8081，浏览器请求图片返回 500；已统一改为 `http://127.0.0.1:8081`。
9. Nginx 的 `/upload/` 原先只挂载运行期上传目录，内置示例图片不可达；已改为代理后端 8081，并移除 compose 中静态与动态目录挂载。

### 3.4 安全与规范检查

- JWT 仅作用于 `/api/v1/**`，Session 策略为 `STATELESS`；未认证访问后台接口返回 401。
- 密码使用 BCrypt；注册必须邮箱激活；登录与注册均有限流。
- 富文本渲染前进行标签、属性与 URL 协议白名单清洗。
- 上传文件使用 UUID 重命名并限制扩展名，避免路径穿越。
- 未发现硬编码 JWT 密钥；密钥来自环境变量或 `.env`。

## 4. 遗留风险与建议

1. access/refresh 令牌存放在浏览器 `localStorage`，一旦发生 XSS 可被读取；建议后续评估改为 HttpOnly Cookie + CSRF 防护。
2. 后台接口日志仍输出到控制台和文件，生产环境建议关闭 MyBatis `StdOutImpl`。
3. 数据库默认账号密码写在 `application.yml`，生产部署必须通过环境变量覆盖。
4. 管理员登录成功率、分页上限等参数目前为代码常量，后续可考虑配置化。
5. 激活流程集成测试 `ActivationFlowIntegrationTest` 依赖本机 MySQL 与真实邮件配置，未纳入默认测试；已同步更新为新的激活链接格式。
6. 后台构建存在单 chunk 超过 500 KB 的提示（Element Plus 体积），不影响运行，可按需做 vendor 拆包。

## 5. 最终结论

旧栈页面、接口、模板、静态资源、依赖与网关配置均已移除，新栈可以独立构建、启动和访问；前台浏览、后台登录入口、公开目录接口、验证码与权限拦截均通过验证。文档已按新栈实际结构与运行方式更新。
