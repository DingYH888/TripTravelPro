## Phase 4：Nginx 统一入口与灰度/回滚

### 1. 部署决策

- 本机 80/443 已被现有 Dify 的 `docker-nginx-1` 占用，未改动 Dify。
- 经确认，travel 使用独立容器 `travel-nginx`，映射 `127.0.0.1:8088:80`。
- 容器通过 `host.docker.internal:host-gateway` 访问宿主机上的 8081/8080。

### 2. 路由布局

|---|---|

- 编排与配置：`docker/nginx/docker-compose.yml`、`docker/nginx/nginx.conf`

### 4. 回滚方式

1. 直接访问旧入口：`http://127.0.0.1:8080/frontdesk/index`、`http://127.0.0.1:8080/backstage/login`。
2. 统一入口回滚：将 `nginx.conf` 中 `location /` 改为代理 `http://host.docker.internal:8080`，执行 `docker exec travel-nginx nginx -s reload`。
3. 停止新入口：`docker compose -f docker/nginx/docker-compose.yml down`，旧系统 8080 不受影响。
4. 后台保留 `/backstage` 双入口，新后台异常时可直接切回。
